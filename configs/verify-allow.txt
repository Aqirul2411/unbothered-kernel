# Config differences we deliberately accept, for IDENTITY=own only.
#
# One extended regex per line, matched against a config line with its leading
# "-" or "+" removed. Blank lines and lines starting with # are ignored.
#
# Rule: a line goes in here only when we know why it changed and we changed it
# on purpose. Everything not listed here fails the build.
#
# The repro identity does not read this file at all: a reproduction has to diff
# clean, no exceptions.

# The rename. This is the whole point of `own`.
^(# )?CONFIG_LOCALVERSION=

# The root driver. `own` tracks the KernelSU-Next tip on purpose, while both
# references were built at earlier points, so new CONFIG_KSU_* symbols appear
# here first. `(# )?` because a disabled option appears as "# CONFIG_x is not
# set", and a driver that dropped an option is exactly the kind of change this
# has to tolerate without hiding it: every accepted line is printed.
#
# Not covered, on purpose: CONFIG_KSU=y and CONFIG_KSU_SUSFS=y are checked
# separately, and losing either fails the build.
^(# )?CONFIG_KSU
^(# )?CONFIG_KPM
